# FB-004 — 实参清理按硬编码函数名 `sum` 整段跳过释放

- **反馈环批次**：第二批（lowering/text 线 (c) 类）
- **源登记**：`docs/divergences/lowering-text.md` D-T3；合编 `docs/DIVERGENCES.md`
- **分类**：Zig 侧缺陷候选 —— 源码机制定案（静默兜底族）
- **Rust 侧处置**：逐字镜像（`crates/sla-codegen-text` call.rs），候主线裁决。

## 机制（Zig 源码位置）

- `src/codegen.zig:9830-9832`：`emitLoweredCallArgCleanups` 中，
  当被调用名 `skip_release_name == "sum"` 时，**整段跳过该调用的
  全部实参释放**。代码无注释、无计划函数/注册表支撑。

## 影响

- 名字碰撞即语义改变：任何用户自定义的 `sum` 函数（与 std 的
  求和无关）调用后其实参一律不释放——所有权记账被一个字符串
  字面量劫持，表现为泄漏或（若别处按已释放处理）反向错误。
- 该跳过对全部实参无差别生效，不是针对特定签名的精确豁免。

## 建议修复形态（仅建议，不预判主线最终形态）

若原意是豁免某个特定的 std `sum`（如迭代器求和的借用形态），
应以函数身份/签名（解析后的目标）判定而非名字字符串；若无
正当豁免对象，直接删除该特判并以语料复验兜底。修复时建议
普查 codegen 内其余按名字字符串硬编码的特判点。

## Rust 侧锚点

`crates/sla-codegen-text` call.rs 逐字镜像该特判并注有源行号；
主线裁决（删除/改身份判定）后，Rust 侧按裁决同步镜像形态，
差分对拍复核同名用户函数场景。
